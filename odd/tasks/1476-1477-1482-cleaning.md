# 1476 / 1477 / 1482 — pre-release audit (2026-09-27) cleaning fixes

## Objective

Fix three bugs found by the pre-release multi-agent audit of `main` at `ebda114`,
all targeted for landing before the 3.2.0 release:

- **#1476**: the signed-URL guard (#1200) only checks the URL BEFORE unwrap. A
  presigned URL (Azure SAS, S3 SigV4, GCS V4) reached through a redirect
  wrapper (google.com/url, l.facebook.com/l.php, AMP, canonical extraction)
  gets its query stripped, breaking the signature (403).
- **#1477**: DNR rule 1000 (Chrome custom-param network strip) has no
  `excludedRequestDomains` and no filter against `domain-rules.json`'s
  `preserveParams`, so a user-added custom param that happens to collide with
  a host's preserved param (e.g. `k` on amazon.*) gets stripped network-side
  even though the JS path and the remote channel both already protect it.
  Violates AGENTS.md: "DNR rules must NOT strip params that domain-rules.json
  marks as preserveParams."
- **#1482**: `btag` (Income Access / Paysafe affiliate attribution tag) sits in
  the global `TRACKING_PARAMS` strip list, so it is removed on every host
  unconditionally, killing creator attribution — the same defect class as
  the `sscid` fix in #1443.
