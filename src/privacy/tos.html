2. What MUGA does

MUGA is a browser extension that:

  • Strips tracking parameters (UTMs, click IDs, and similar) from URLs before pages load
  • Redirects AMP pages to their canonical article URLs
  • Blocks <a ping> tracking beacons on link clicks
  • Unwraps link-share wrappers where the destination is embedded in the URL's query string (Facebook, Instagram, certain Twitter templates). Affiliate-redirect networks are deliberately preserved so the creator's commission survives the click — see the Privacy Policy for the full list and rationale
  • Optionally resolves generic URL shorteners (bit.ly, tinyurl.com, t.co, link.medium.com, lnkd.in, fb.me, ebay.to) directly in your browser via a standard HTTP fetch — no URL is sent to any MUGA server. Off by default; requires optional host permissions for the eight shortener domains. Affiliate-redirect networks are NEVER resolved this way
  • Optionally adds our affiliate tag to links that carry no affiliate tag, if you have opted in

You have full control over every feature. MUGA never collects, sells, or shares your browsing data. Any feature that contacts an external service requires your explicit action.

3. Affiliate model and disclosure

MUGA is maintained by an independent developer. To sustain active development, MUGA participates in affiliate programs operated by third-party stores, including but not limited to the programs of supported stores listed in the source code.

If you opted in during onboarding, MUGA adds our affiliate tag to URLs that contain no existing affiliate tag. This does not change the price you pay. Affiliate tags tell the store who referred the visit, nothing more. The developer may earn a small commission from qualifying purchases.

  • By default, MUGA does not replace an affiliate tag that is already present in a URL. Replacing requires a separate, deliberate opt-in by the user
  • Affiliate tag injection only applies to the supported stores explicitly listed in the source code
  • You can disable affiliate tag injection at any time in the Extension's Settings, no questions asked
  • The "Remove all affiliate tags from other sources" option strips third-party tags. MUGA's own tag is preserved only when you also have affiliate injection enabled on this device. If you have injection off, MUGA's tag is treated like any other and removed too — symmetric with your stated preference
  • The developer may earn commissions from qualifying purchases through supported affiliate programs. This disclosure is required by the operating agreements of those programs
