2. What MUGA does

MUGA is a browser extension that:

  • Strips tracking parameters (UTMs, click IDs, and similar) from URLs before pages load
  • Redirects AMP pages to their canonical article URLs
  • Blocks <a ping> tracking beacons on link clicks
  • Unwraps link-share wrappers where the destination is embedded in the URL's query string (Facebook, Instagram, certain Twitter templates). Affiliate-redirect networks are deliberately preserved so the creator's commission survives the click; see the Privacy Policy for the full list and rationale
  • Resolves well-known generic URL shorteners directly in your browser via a standard HTTP fetch; no URL is sent to any MUGA server. This is split by privacy risk into two separate settings. Resolving a short link when you open it is on by default: you were navigating there anyway, so the shortener receives the request your click would have made, and MUGA hands you the cleaned destination. Resolving a short link when you merely hover over it is off by default and opt-in, because it would contact the shortener for a link you only looked at. On Chrome the extension's existing host access covers this; on Firefox, enabling it requests permission for the shortener domains. Neither runs on passive page load, and either can be turned off in Settings. Affiliate-redirect networks are NEVER resolved this way
  • Fetches weekly rule updates by default: about once a week, MUGA downloads an updated tracking-parameter list from rules.muga.app over HTTPS. The request is Ed25519-signed and sent with credentials omitted: no browsing history, no cookies, no identifiers, no request body. You can turn it off at any time in Settings, which returns the Extension to making no outbound requests
  • Respects the original referral on links that already carry an affiliate tag, and lets you optionally remove third-party affiliate tags in Settings; MUGA does not add any affiliate tag of its own

You stay in control of every feature. MUGA does not collect, sell, or share your browsing data. Every feature that contacts an external service is listed above, carries no data about you, and can be turned off in Settings.

3. Affiliate model and disclosure

MUGA does not add any affiliate tag of its own, and it does not monetize your clicks. By default, MUGA respects the original referral: if a creator you follow earned an affiliate tag on a link, it stays, so they keep their credit. Affiliate tags tell the store who referred the visit, nothing more, and this does not change the price you pay.

  • By default, MUGA leaves an affiliate tag that is already present in a URL in place. Stripping third-party tags is a separate choice that is always yours
  • The "Remove all affiliate tags from other sources" option strips third-party tags from links, leaving none behind. This is an optional extra, off by default: MUGA never adds its own tag in their place
  • MUGA does not participate in affiliate programs and earns no commission from your clicks or purchases
