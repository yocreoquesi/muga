window.name — CSP-immune defuser smoke

Validates the Firefox MV2 wrappedJSObject wrap under a strict page CSP (#509 / B12).

Before you run

  1. Load MUGA unpacked in Firefox (npm run dev:firefox or about:debugging).
  2. Make sure MUGA is enabled, onboarding is complete, and active-defense is ON (default). The gate stays closed otherwise and every case will show the dirty value.
  3. Serve this folder: npm run test:serve, then open http://localhost:5555/window-name-csp-immune.html.
  4. Click the button below (give the page a second after load so the async prefs gate opens).

How to read it. Case A is the real assertion: a page script writes a URL with utm_source into window.name, and reading it back must return the URL without utm_source. Because this page's CSP is script-src 'self', an injected <script src="moz-extension://…"> would be blocked — so a PASS here proves the wrap survives strict CSP. On an unported build, Case A fails on Firefox under this CSP. The accessor installed line tells you whether Firefox accepted the wrappedJSObject property redefine at all — if it reads no on Firefox, the Xray wrap was rejected and that is the thing to report.
