MUGA Clean: Manual Test Battery

Runs the real engine + adapter + UI at web/index.html · #1029

Setup

Step 1: serve the actual tool: npm run test:serve:web

Step 2: open http://localhost:5557/ in a second tab. That page IS web/index.html loading the real cleaner-bundle.js + adapter.js + ui.js, not a mock.

Step 3: for each case below, click the input URL to select it, copy it (Ctrl/Cmd+C), paste it into the tool's textarea, click Clean this URL, and compare the result against Expected.

Tracking parameter removal strip

WC-01
Multiple tracking params stripped, functional param kept
https://example.com/search?q=shoes&utm_source=newsletter&utm_medium=email&fbclid=IwAR0abc&gclid=Cj0KCQjw
Expected: https://example.com/search?q=shoes · 4 tracking parameters removed (utm_source, utm_medium, fbclid, gclid)
WC-02
mc_cid stripped
https://example.com/article?mc_cid=abc123
Expected: https://example.com/article · 1 tracking parameter removed (mc_cid)

Redirect wrapper unwrapping unwrap

WC-03
google.com/url unwraps to the real destination, cleaned
https://www.google.com/url?q=https%3A%2F%2Fexample.com%2Fpage%3Futm_source%3Dnewsletter
Expected: https://example.com/page · unwrapped, real destination example.com · 1 tracking parameter removed (utm_source)
WC-04
l.facebook.com/l.php unwraps to the real destination
https://l.facebook.com/l.php?u=https%3A%2F%2Fexample.com%2Fpage
Expected: https://example.com/page · unwrapped, real destination example.com · no tracking parameters to remove

Affiliate / referral preservation affiliate

No-op on already-clean input

WC-06

Cross-cutting checks

  • DevTools Network tab: zero requests fire during any of the above (fully local).
  • DevTools Console: zero errors for any case, including the negatives.
  • Keyboard-only flow: Tab to the textarea, type a URL, Tab to Clean, press Enter/Space, Tab to Copy, press Enter/Space. Clipboard should contain the cleaned URL.
  • Copy button is disabled until a successful clean, then enabled.
